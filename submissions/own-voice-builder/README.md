# Own Voice Builder

Analyze your own sent email or Teams messages and return a communication profile, save a requested memory profile, or create a reusable voice skill.

## Available Modes

Specify email, Teams, or both as the source and choose a profile in the current conversation, a persistent memory profile, or a reusable voice skill. Persistent storage is used only when requested and available. The skill reports what was actually saved.

- Includes the Communication Style Analyzer workflow by Srinivas Varukala. [Original source](https://github.com/TedTschopp/cat-agent-skills/tree/1a3e42195454e4e4159a327d175a72870d505268/submissions/style-analyzer).
