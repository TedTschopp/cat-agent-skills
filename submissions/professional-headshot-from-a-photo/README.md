Create a professional headshot from an uploaded photo while preserving the person's identity and natural facial character. The prompt asks about the intended use, style, lighting, and background, then offers 2–3 portrait directions before creating the selected version.

## How to Use This Prompt

1. Open an image-editing conversation in a tool that supports uploaded reference photos.
2. Upload the photo and paste the prompt.
3. Answer the three questions about intended use, style, and preferred lighting and background. Mention LinkedIn if the portrait is for your profile.
4. Select one of the proposed portrait directions to create the headshot.

The prompt preserves identity, facial structure, skin tone, age, hair, defining features, and natural skin texture. It allows changes to clothing, pose, expression, lighting, background, and crop to suit the selected direction.
