# Swiss Design Images

Create new artwork or restyle a supplied image using Swiss graphic design, also known as the International Typographic Style. The skill uses modular grids, asymmetrical balance, clear hierarchy, restrained color, and precise sans-serif typography while preserving the requested subject and exact supplied text.

## Use the Skill

Install the downloaded skill folder in an agent that supports Agent Skills and has an image-generation tool. Keep `SKILL.md` and `agents/` together. The skill can also return a complete generation prompt when that is what you request.

Describe the subject, intended use, dimensions or aspect ratio, and any wording that must appear. Attach an image when you want it restyled. Without a specified format, the skill uses a portrait poster ratio of 2:3.

Example: “Use $create-swiss-images to illustrate a bridge between human judgment and machine assistance. Use a landscape 16:10 composition and no text.”

Swiss refers to the design language. National symbols are included only when requested. Specific print dimensions and production readiness depend on the generated file and must be verified for the intended use.
