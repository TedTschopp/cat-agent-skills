# Aquatint Etching Images

Create a new illustration or restyle a supplied image as an etching and aquatint print. Fine irregular linework, layered crosshatching, granular darkness, and restrained ivory paper give the result the character of a handmade intaglio impression.

## Use the Skill

Install the downloaded skill folder in an agent that supports Agent Skills and has an image-generation tool. Keep `SKILL.md`, `agents/`, and `assets/style-reference.png` together. The bundled image anchors the print technique and atmosphere; your request determines the subject and composition.

Describe the subject, action, setting, aspect ratio, and any details that must remain. Attach an image for restyling. Without a specified format, the skill uses a landscape sheet near a 10:7 ratio.

Example: “Use $create-aquatint-etching-images to draw an old observatory under a cloudy sky, with fine etched stonework, deep granular shadows, and warm ivory paper.”

You can request a gentler mood, a different palette, a borderless composition, or another aspect ratio. Inspect the resulting file before using it in print or as part of a series.
